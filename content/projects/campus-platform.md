## 项目背景

四维优校综合管理平台是为教育机构打造的一站式数字化管理解决方案。系统涵盖教学、人事、财务、后勤等核心业务，帮助学校实现信息化管理升级。

## 技术架构

- **前端框架**: Vue.js 2.6 + TypeScript + Ant Design Vue 1.5
- **状态管理**: Vuex + vuex-module-decorators
- **可视化**: ECharts + AntV G2
- **富文本编辑**: CKEditor 5
- **日程管理**: FullCalendar
- **国际化**: Vue i18n
- **构建工具**: Vue CLI 4

## 核心功能模块

### 教学管理
- 课程管理、排课系统
- 考试管理、成绩管理
- 教学评估、课程评价

### 人事管理
- 教师档案、职称评定
- 考勤管理、绩效考核
- 培训管理、专业发展

### 学生管理
- 学籍管理、异动跟踪
- 宿舍管理、生活服务
- 奖惩管理、综合素质评价

### 行政办公
- 公文流转、会议管理
- 资产管理、采购审批
- 合同管理、财务管理

## 项目亮点

1. **多租户架构**: 支持多校区独立部署，数据隔离
2. **模块化设计**: 35+ 业务模块，高内聚低耦合
3. **富文本编辑**: CKEditor 5 集成，支持复杂文档编辑
4. **实时通信**: WebSocket 消息推送，实时通知
5. **可视化大屏**: ECharts 图表，数据大屏展示

## 部署架构

- 多环境配置（测试/正式/校区/东海等）
- 支持 Docker 容器化部署
- Nginx 反向代理 + CDN 静态资源
