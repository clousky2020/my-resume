## 项目背景

为人才住房管理部门打造的移动端申请平台，实现住房申请全流程线上化，包括在线申请、资格审核、摇号选房等功能，累计服务用户超1万人次，确保摇号过程公平公正。

## 技术架构

### 技术栈

- **框架**：Taro 3.x + Vue 3
- **语言**：TypeScript
- **状态管理**：Pinia
- **UI 组件**：Taro UI Vue 3
- **后端**：Node.js + PostgreSQL

## 核心功能模块

### 在线申请

- **政策查询**：最新人才住房政策
- **资格自测**：在线评估是否符合申请条件
- **材料上传**：证照电子化，在线上传
- **申请进度**：实时查看申请状态

### 资格审核

- **自动初审**：系统自动校验材料完整性
- **人工复审**：部门在线审核
- **审核结果**：短信+小程序双重通知

### 摇号选房

- **摇号直播**：实时直播摇号过程
- **摇号结果**：即时公布中签名单
- **选房通知**：中签用户选房提醒

### 签约入住

- **合同签署**：电子合同在线签署
- **入住办理**：在线预约入住时间
- **维修申请**：在线提交维修需求

## 项目亮点

1. **公平公正**：摇号算法公开透明，可验证
2. **全流程线上**：从申请到入住全程在线
3. **实时通知**：每个节点及时推送通知
4. **数据分析**：实时统计申请数据

## 技术难点与解决方案

### 摇号系统

- 采用国家认证的随机算法
- 摇号过程全程录像存证
- 多人同时观看流畅无卡顿

### 并发控制

- 选房时段精确控制并发
- 实时锁机制防止重复选房
- 异常情况自动回滚
